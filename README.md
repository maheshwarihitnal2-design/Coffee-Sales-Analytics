Coffee Sales Analytics Project

Project Overview

This project analyzes coffee shop sales data to identify sales trends, customer purchasing patterns, and top-performing products.

Tools & Technologies

- Python
- Pandas
- Jupyter Notebook
- Power BI
- Excel

Project Files

- "analysis.ipynb" – Python data analysis and visualizations.
- "power1.pbix" – Interactive Power BI dashboard.
- "product_analysis.xlsx" – Product analysis results.
- "Coffee_Sales_Analysis_Results.xlsx" – Coffee sales analysis results.

Key Analysis

- Revenue analysis by hour
- Best-selling products
- Revenue by product category and type
- Store location performance
- Product sales trends

Project Objective

To transform raw coffee sales data into meaningful insights that support better business decisions.
